# Struct Clone

Uma recriação da página inicial da Struct, desenvolvida para praticar e consolidar os fundamentos do desenvolvimento web front-end.

## 🎯 Sobre o Projeto

Este projeto é um clone da interface do site da [Struct](https://struct.unb.br).

## 🚀 Como rodar o projeto

Como este é um projeto construído com arquivos estáticos, não é necessária nenhuma instalação ou configuração de ambiente.

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador.
